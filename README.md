# VisiPulse
## نظام الإنذار المبكر وحوكمة البنية التحتية للمنشآت الصحية

> **The Flow of Smart Healthcare**

---

### عن النظام
نظام ذكي متكامل مبني بلغة Python باستخدام إطار عمل Streamlit مع قاعدة بيانات SQLAlchemy و SQLite. يهدف النظام إلى تمكين المنشآت الصحية من التنبؤ بالأعطال التقنية والطبية قبل وقوعها، وحوكمة تدفقات البيانات وفقاً لأعلى معايير الأمن السيبراني والممارسات العالمية.

---

### الهيكل المعماري والوكلاء الأذكياء (AI Agents)
يستند النظام إلى معمارية متعددة الطبقات تدار بواسطة وكلاء ذكاء اصطناعي متخصصين:
- **وكيل البنية التحتية (Infrastructure Agent):** مراقبة استهلاك المعالجات ودرجات حرارة الخوادم للتنبؤ بالمخاطر.
- **وكيل الأنظمة الطبية (Medical Systems Agent):** متابعة جاهزية الأجهزة الحيوية ومستويات البطاريات وأعطال الأجهزة.
- **وكيل الدعم الفني (IT Helpdesk Agent):** توليد التذاكر التلقائية وإدارة البلاغات بحسب مستوى الخطورة.
- **وكيل حوكمة البيانات (Data Governance Agent):** تدقيق جودة البيانات السريرية والتقنية وضمان سلامة السجلات.

---

### البوابات والصلاحيات (RBAC)
يحتوي النظام على ثلاث بوابات رئيسية مصممة خصيصاً لتلبي احتياجات الأدوار المختلفة:
1. **بوابة تقنية المعلومات:** تضم أقسام الدعم الفني، البنية التحتية، الأنظمة والتطبيقات، وإدارة الصحة الإلكترونية (مع التركيز على دور مدير الجودة وحوكمة البيانات).
2. **بوابة الإدارة العليا:** توفر مؤشرات أداء رئيسية (KPIs) ولوحات تحكم لاتخاذ القرارات الاستراتيجية واعتماد خطط الصيانة.
3. **بوابة الموظف:** تتيح متابعة الأجهزة والعهدة الخاصة ورفع التذاكر الاستباقية.

---

### الضوابط الأمنية وحوكمة الوصول
- تطبيق نظام التحكم في الوصول بناءً على الأدوار (RBAC).
- سياسات صارمة لكلمات المرور وتاريخ التحديثات لمنع إعادة استخدام الكلمات السابقة.
- مراقبة خمول الجلسات والإغلاق التلقائي لتعزيز أمان المنظومة الصحية.
- سجل تدقيق شامل (Audit Logs) لكافة العمليات الحساسة.
